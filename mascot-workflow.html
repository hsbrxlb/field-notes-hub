# Mascot Design Workflow
Version: 1.0

## When to use this
Use this workflow to create a brand mascot, revise an existing character, or extend an accepted character into new poses. It works with an AI assistant that can inspect reference images and create or edit images. If those tools are unavailable, prepare the brief and prompts and report which images remain unmade.

## Task brief
Complete these fields from the user's request and supplied references:
- Brand and sources for its facts:
- Audience and intended uses:
- Smallest display size and required file formats:
- Character personality and degree of human expression:
- Body inspiration and preferred visual style:
- Features to preserve:
- Directions and colors to avoid:
- Official logo asset, if lettering is required:
- Reference image and version to continue:
- Latest feedback and the specific change requested:
- Output location and any authorized publishing destination:

Ask about missing information only when it would change the design. Keep uncertain brand facts marked as unknown. Set brand-specific colors and proportions for this task.

## 1. Choose the character
Describe why its shape belongs to the brand, what makes its silhouette recognizable, and how its gaze or movement expresses personality. Choose the body and visual style separately. A new color alone does not create a new character.

Match movement to anatomy: mechanical joints, animal limbs and abstract shapes each need consistent behavior. To make a device feel friendlier, test gaze and purposeful movement before adding human limbs.

## 2. Establish a master image
Create one complete character with all important body parts visible. Inspect personality, silhouette, proportions and physical connections. Repair the main problem in this image before expanding the set.

Once the master passes visual review, record its fixed identity: body proportions, outline, eye placement, limb count, joints, materials, color areas, distinctive features and logo placement. Use that exact master as the reference for subsequent images.

## 3. Extend the character
Unless the brief specifies otherwise, create four separate images:
1. Complete character in a clear standing or resting pose.
2. Side or rear view showing how the body connects.
3. A useful action in context.
4. A distinct movement or expression.

Keep the same identity across the set. Adjust actions to the character's abilities. Deliver each image separately; a contact sheet is an additional comparison aid.

For each image, write a complete prompt in this order:
- Intended use and character intent.
- Fixed identity and reference version.
- Pose, expression, camera and composition.
- Joints, support and contact with props.
- Materials and distribution of colors.
- Logo surface and placement, if requested.
- Background and excluded elements.

Use the supplied official logo when required. Check spelling, count and perspective. Keep an unlettered original. Without an official asset, identify lettering as a placement study.

## 4. Inspect the exact files
Inspect every output at full size and alongside its master. Check gaze, limb count, connected joints, weight support, prop contact, outline and uncropped composition.

Compare all four images for changes in face, body proportions, materials, color areas and distinctive parts. Export 32px and 64px previews from the current files, and inspect them at their actual size. Also check grayscale, silhouette, and light and dark backgrounds.

Record specific findings against each file. Image dimensions and successful downloads verify technical properties. Visual appeal requires image inspection; user preference and trademark clearance require separate evidence.

## 5. Revise and retain evidence
Translate feedback into a concrete change to shape, proportions, expression, color, pose or presentation. State which identity features must remain. Revise affected images and repeat the affected checks.

Keep previous images and feedback. After an interrupted generation, inspect saved outputs and continue the missing items. Report unavailable tools or failed files without marking the set complete.

Keep one record per image:
- Brand, character, version and view.
- Output filename and reference filename.
- Complete prompt.
- Actual generation tool, when known.
- Technical checks and visual findings.
- Feedback and revision outcome.

## Delivery
Provide the master, four independent images when requested, previews derived from those files, and the per-image record. Keep high-resolution originals; create separate optimized copies for web display.

For an authorized display page, show complete images with natural pose captions, group them by character, preserve earlier versions, and check desktop and mobile layouts. Verify the published page separately if publication was requested.

Close with the delivered files, checks performed, unresolved issues and the exact version to use next.
